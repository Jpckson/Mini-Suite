# Mini Suite

**Fixing Windows. One tool at a time.**

A collection of free, private, open-source-powered Windows tools that run entirely on your machine. No uploads, no ads, no accounts, no paywalls.

Built by [Jackson](https://jpk.la) out of frustration with bloated web tools that limit uploads, save your files, and make you wait.

---

## Why Mini Suite?

Most file utilities online limit your uploads, store your files on a server, plaster the page with ads, or take forever. Mini Suite tools do the opposite:

- 🔒 **Private** — everything runs locally; your files never leave your computer
- ⚡ **Fast** — no upload/download round trips
- ♾️ **Unlimited** — no size limits, no file-count limits
- 🆓 **Free** — zero ads, zero accounts, zero paywalls
- 🛡️ **No admin required** — installs and runs without administrator privileges

## Tools

### Mini Converter
Quickly convert files between formats locally using a minimal open-source library. Speedy, private, and unlimited.

**Supported formats**

| Type | Formats |
|------|---------|
| Images | JPG, JPEG, PNG, BMP, WEBP, TIFF, AVIF, ICO |
| Audio | MP3, WAV, FLAC, AAC, OGG, M4A |
| Video | MP4, MKV, AVI, MOV, WEBM |

**Dependencies:** FFmpeg Essentials (`a757b708ae`)

---

### Mini Compress
Compress images, videos, and audio locally using reliable open-source libraries — without compromising privacy, integrity, or efficiency.

**Supported formats**

| Type | Formats |
|------|---------|
| Images | JPG, JPEG, PNG, BMP, WEBP, TIFF, AVIF |
| Audio | MP3, WAV, FLAC, AAC, OGG, M4A |
| Video | MP4, MKV, AVI, MOV, WEBM |

**Dependencies:** FFmpeg Essentials (`a757b708ae`), pngquant (`3.0.3`)

## FAQ

**Is Mini Suite really free?**
Yes. Every tool is completely free with no ads, accounts, or paywalls. Support is optional via the Donate page.

**Do my files ever get uploaded anywhere?**
No. Everything runs locally using open-source libraries. Nothing is sent to a server.

**Do I need admin privileges?**
No.

**Are there file size or count limits?**
None. Convert or compress multiple files at a time.

**Will there be more tools?**
Yes — as more "why doesn't Windows just do this?" problems come up, they'll get built and added here.
